# B站考古工具 · 时间胶囊

一款适用于 `search.bilibili.com` 的浏览器扩展，为B站搜索添加**拖拽时间轴**、**分区筛选**、**排序方式**和**随机跳跃考古**功能，帮助用户在海量视频中找回那些年的记忆。

![版本](https://img.shields.io/badge/version-2.2-blue)
![Manifest](https://img.shields.io/badge/Manifest-V3-green)

## 功能特点

- 📅 **拖拽时间轴** — 自由选择 2009 年至今任意年月范围，精确到月
- 📂 **分区筛选** — 支持动画、音乐、游戏、生活、科技等15个B站分区
- 📊 **排序方式** — 综合排序、最新发布、最多播放、最多收藏、最多弹幕
- ⚡ **快速搜索** — 预设18个热门考古关键词，一键直达
- 🎲 **随机跳跃模式** — 随机组合时间范围+分区+关键词（播放量排序），发现意外惊喜
- 🖱️ **悬浮可拖拽** — 面板可在页面内自由移动位置
- 🔄 **URL状态同步** — 刷新页面后自动恢复筛选条件

## 安装方法

### Chrome / Edge

1. 下载或克隆本仓库到本地
2. 打开 `chrome://extensions`（Edge 用户打开 `edge://extensions`）
3. 开启右上角 **开发者模式**
4. 点击 **加载已解压的扩展程序**
5. 选择本仓库文件夹即可

### 验证安装

1. 访问 [B站搜索页](https://search.bilibili.com/all?keyword=test)
2. 页面左上角应显示 **🔍 考古时间胶囊** 悬浮面板
3. 如果未出现，尝试点击页面空白处或滚动一下

### 更新方法

修改代码后，在扩展管理页面点击 **重新加载** 按钮，然后刷新B站搜索页。

## 核心参数说明

扩展通过以下URL参数与B站搜索API交互：

| 参数 | 说明 | 示例 |
|------|------|------|
| `keyword` | 搜索关键词 | `keyword=初音未来` |
| `stime` | 开始时间（Unix时间戳） | `stime=1325347200`（2012年1月1日） |
| `etime` | 结束时间（Unix时间戳） | `etime=1388505600`（2014年1月1日） |
| `tids` | 分区ID（0表示全部分区） | `tids=1`（动画分区） |
| `order` | 排序方式 | `order=pubdate`（最新发布） |

## 二次开发

### 调整时间轴范围

时间轴起始年份由 `content.js` 中的 `TIMELINE_MIN_YEAR` 常量控制，结束月份自动取当前年月：

```javascript
const TIMELINE_MIN_YEAR = 2009; // 修改此值可调整最早可选年份
```

### 添加新的分区

编辑 `content.js` 中的 `PARTITIONS` 数组：

```javascript
const PARTITIONS = [
  { value: '0', label: '全部' },
  // 添加新分区...
  { value: '234', label: '新分区' },
];
```

### 添加预设关键词

编辑 `content.js` 中的 `KEYWORD_PRESETS` 数组：

```javascript
const KEYWORD_PRESETS = [
  '初音未来', '东方Project',
  // 添加新关键词...
  '新预设词',
];
```

### 修改默认配置

- **默认时间范围**：在 `resetFilters()` 函数中修改 `setTimelineFromIndices(...)` 的参数
- **默认分区**：修改 `partitionSelect.value` 的默认值
- **默认排序**：修改 `orderSelect.value` 的默认值

## 技术架构

- **架构模式**：单内容脚本（Single Content Script）
- **UI构建**：DOM API 直接创建元素，无第三方依赖
- **状态管理**：通过URL参数同步状态，`autoFillFromUrl()` 实现初始化回填
- **拖拽实现**：原生 mousedown/mousemove/mouseup 事件，位置约束在视口内
- **样式隔离**：所有样式以 `#bili-archaeology-tool` 为作用域根，避免污染宿主页面
- **层级控制**：`z-index: 2147483647`（最大安全整数）确保面板始终置顶
